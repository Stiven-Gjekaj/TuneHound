# The palette of TuneHound

The wordmark, the logo, and the TUI use these colours.
The README must use the same values in its badges.

## Colours

| Name     | Hex       | Where it is used                                      |
| -------- | --------- | ----------------------------------------------------- |
| Panel    | `#070b14` | The background of the banner, the logo, and the TUI   |
| Panel 2  | `#0f172a` | The top of the logo tile, the header of the TUI       |
| Border   | `#1e3a4a` | The thin border of the logo tile                      |
| Cyan     | `#22d3ee` | The hound head, the banner border, the first badge    |
| Blue     | `#60a5fa` | The second stop of the word gradient                  |
| Violet   | `#a78bfa` | The third stop of the word gradient                   |
| Pink     | `#f472b6` | The nose, the sound bars, the last stop of the word   |
| Pale     | `#e0e7ff` | A pale badge, for the release                         |
| Pale 2   | `#fce7f3` | A pale badge, for the licence                         |

The word gradient runs along the word.
It starts with Cyan and ends with Pink.
The stops are at 0, 0.4, 0.72, and 1.
